# 🌷 PROJECT BLOOM

> "A bouquet across the distance."

PROJECT BLOOM is a handcrafted interactive web experience created as a digital bouquet for someone who cannot yet receive real flowers in person.

Rather than behaving like a traditional website, Project Bloom is designed as a short emotional journey:

Silence  
→ Wish  
→ Hope  
→ Life  
→ Distance  
→ Bloom  
→ Permanence

The project emphasizes atmosphere, organic animation, subtle storytelling and long-term emotional value over visual spectacle.

---

# Vision

The guiding question for every creative and technical decision is:

> **Would this make her smile when she revisits it a year from now?**

If a feature is technically impressive but emotionally distracting, it should not exist.

Nothing exists purely because it "looks cool."

Everything should contribute to the feeling of receiving flowers from someone who cannot yet place them in her hands.

# Design Philosophy

Project Bloom prioritizes:

- emotional pacing
- quiet beauty
- natural movement
- botanical believability
- subtle magic
- timeless typography
- responsive design
- accessibility
- maintainable architecture

The page should resemble an interactive short film rather than a traditional website.

---

# Technical Goals

- Static website
- No framework
- No React
- No build system
- ES Modules only
- Mobile-first
- Responsive
- Accessible
- Production-ready
- Zero console errors

Runs from any local HTTP server.

# Compatibility

Project Bloom intentionally preserves:

- existing folder structure
- asset paths
- SVG artwork
- audio assets
- CSS architecture
- modular JavaScript

Working files are preserved whenever possible.

Files are replaced only when necessary because of:

- syntax errors
- module conflicts
- missing implementations
- parsing failures
- architectural incompatibility
